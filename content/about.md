I am a Tech Lead and DevOps / DevSecOps engineer based in Dhaka, Bangladesh. I
build and operate systems end to end — from Laravel applications and Python
automation down to the Linux servers they run on.

## What I actually do

- **Build** — Laravel and Flask applications, from case-filing workflows for the
  judiciary to multi-tenant SaaS platforms.
- **Operate** — Linux and LiteSpeed under cPanel / WHM, CloudLinux LVE tuning,
  Imunify360, DNS and mail, migrations with no downtime.
- **Harden** — DevSecOps practice: least-privilege access, TLS everywhere,
  dependency and header hygiene, and finding the gaps before someone else does.
- **Integrate** — JWT-based APIs, Firebase Admin and FCM, Google and Gmail APIs,
  SocketIO for anything that has to be live.

## How I work

I prefer to own the whole path to production. Writing the application and then
handing it to someone else to deploy hides exactly the problems that cause
outages, so I take responsibility for both sides: the code and the box it
lives on.
